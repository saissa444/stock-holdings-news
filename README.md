# 持股新聞

顯示台股＋美股持倉的即時股價、損益（全部換算台幣合計），並整理每檔持股的每日新聞。
iPhone（Safari／主畫面）、Mac、Windows 的 Chrome／Edge 都能用，持倉存在你自己的 Google 試算表，所有裝置看到同一份。

```
GitHub Pages（這個網頁）  ──讀寫──▶  你的 Google Apps Script（後端）
                                        ├─ 持倉：你的 Google 試算表
                                        ├─ 台股：證交所／櫃買 MIS → 備援 Yahoo
                                        ├─ 美股、匯率：Yahoo → 匯率備援 open.er-api
                                        └─ 新聞：Google 新聞
```

## 一、建立後端（約 10 分鐘，只做一次）

1. 到 [Google 試算表](https://sheets.new) 建立一份新的試算表，命名例如「持股新聞」。
2. 選單「擴充功能 → Apps Script」。把編輯器裡原本的內容全部刪掉，貼上 `backend/Code.gs` 的全部內容，按存檔（💾）。
3. 上方函式選單選 `setup`，按「執行」。
   - 第一次會要求授權：選你的帳號 → 出現「Google 尚未驗證這個應用程式」時按「進階」→「前往（不安全）」→「允許」。這是你自己寫的程式，只存取這份試算表和外部報價網站。
   - 執行完，試算表會多出「持倉」和「說明」兩個工作表，「說明」裡有**存取金鑰**。
4. （建議）函式選單選 `selfTest` 執行一次，在「執行記錄」確認各資料來源都是 `"ok": true`。
5. 右上角「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（沒有金鑰的人仍然讀不到資料）
   - 按「部署」，複製「網頁應用程式網址」（以 `/exec` 結尾）。

## 二、在第一台裝置設定（建議用電腦）

1. 打開 App 網址 → 右上角 ⚙️「設定」。
2. 貼上「網頁應用程式網址」與「存取金鑰」→「測試連線」，每一項都是 ✓ 後按「儲存設定」。
3. 按「新增持股」輸入代號、股數、平均成本。也可以直接在試算表「持倉」工作表輸入（代號欄已設成文字格式，0050、00878 不會掉 0）。

## 三、其他裝置

- 在已設定好的裝置：設定 →「分享設定碼給其他裝置」（AirDrop、LINE 傳給自己都可以）。
- **iPhone 主畫面 App**：用 Safari 開 App 網址 → 分享 →「加入主畫面」→ **從主畫面圖示打開** → 設定 → 把設定碼貼到「設定碼」欄 → 儲存。
  主畫面 App 和 Safari 的資料是分開的，所以要在主畫面 App 裡貼一次。
- Mac／Windows 的 Chrome、Edge：開網址 → 設定 → 貼設定碼。也可以直接開分享訊息裡的連結，會自動套用。

## 四、日常使用

- 打開就會抓最新股價與新聞；切回 App 超過 1 分鐘會自動更新；台股或美股開盤時間內每分鐘更新股價。
- 點持股看明細與該檔新聞；點上方比重條的色塊也能直接開。
- 美股建議在「編輯 → 新聞關鍵字」填中文名（如：輝達、蘋果），中文新聞會更準。
- 損益預設扣除台股預估賣出手續費與證交稅（與券商 App 算法一致），手續費折扣在設定裡調整，也可以關閉。

## 更新後端程式碼

改了 `Code.gs` 後要「部署 → 管理部署作業 → ✏️ 編輯 → 版本選『新版本』→ 部署」。這樣網址不變，各裝置不用重設。
（如果按的是「新增部署作業」會產生新網址，所有裝置都要重新設定。）

## 金鑰外流時

在 Apps Script 執行 `resetToken()`，會產生新金鑰；各裝置重新輸入即可。

## 已知限制

- 台股報價來自證交所盤中 5 秒快照；剛好沒成交時用買賣中價，明細會標示。美股報價不含盤前盤後。
- 開盤時間判斷沒有排除國定假日（只影響自動更新頻率，不影響資料正確性）。
- Google 新聞、Yahoo 都是免費公開來源，偶爾會限流；App 會顯示哪一項沒抓到，稍後重新整理即可。設定 →「測試連線」可看各來源狀態。
- 匯率取不到時會用上一次的匯率並標示。
